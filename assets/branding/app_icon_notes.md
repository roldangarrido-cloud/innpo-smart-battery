# INNPO Smart Battery App Icon

## Concepto recomendado

Icono simplificado para uso como launcher icon y favicon de producto:

- Fondo azul INNPO `#2B6F9C`.
- Batería blanca como contenedor principal.
- Núcleo azul con rayo blanco para energía/control.
- Señal Bluetooth integrada en el lateral derecho.
- Estilo plano, técnico y legible en tamaños pequeños.

## Por qué no usar el logotipo completo

El logotipo completo puede perder legibilidad en tamaños de 24-48 px. Para icono de app se recomienda usar un símbolo propio del producto, manteniendo la identidad cromática INNPO.

## Uso recomendado

- Launcher icon Android/iOS.
- Icono simplificado en pantallas de carga pequeñas.
- Favicon de panel web futuro.
- Avatar técnico para documentación o soporte.

## Exportación

Usar `innpo_app_icon_concept.svg` como fuente maestra y exportar a:

- 1024x1024 para App Store.
- 512x512 para Google Play.
- Adaptive icon foreground Android, manteniendo margen de seguridad.
- PNGs iOS mediante `flutter_launcher_icons` cuando se active la generación definitiva.
